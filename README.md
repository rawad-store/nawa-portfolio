# نواة — الحزمة النهائية

تطبيق PWA عربي لتحليل الأسهم وإدارة قائمة المتابعة والمحفظة الفعلية محليًا في المتصفح. لا يوجد خادم ولا تداول آلي، ولا تُرسل كميات الملكية أو متوسطات التكلفة إلى GitHub.

## الرفع الصحيح إلى GitHub Pages

ارفع محتويات هذه الحزمة إلى **جذر** المستودع، لا ترفع ملف ZIP نفسه ولا تضع الملفات داخل مجلد إضافي. يجب أن تظهر الملفات هكذا:

```text
index.html
manifest.webmanifest
sw.js
assets/
data/
icons/
```

مجلد `icons` ضروري للتثبيت كتطبيق، ويجب أن يحتوي على `icon-192.png` و`icon-512.png` و`icon-maskable-512.png` و`apple-touch-icon.png`. بعد الرفع فعّل GitHub Pages من `Settings → Pages → Deploy from a branch → main → / (root)`.

## التثبيت على الهاتف

افتح رابط GitHub Pages عبر HTTPS في Chrome أو Edge، انتظر تحميل الصفحة مرة واحدة، ثم استخدم زر «تثبيت نواة كتطبيق» إذا ظهر أو قائمة المتصفح «تثبيت التطبيق / إضافة إلى الشاشة الرئيسية». في iPhone افتح الرابط في Safari ثم «مشاركة → إضافة إلى الشاشة الرئيسية».

إذا لم يظهر التثبيت، تأكد أن روابط الأيقونات لا تعطي 404 وأن الصفحة تعمل عبر HTTPS، ثم أغلق النسخة المثبتة القديمة وافتح الرابط من جديد.

## الكاش والتحديث

يستخدم Service Worker الإصدار `v7`. عند رفع إصدار جديد يتحدث غلاف التطبيق شبكيًا أولًا، بينما تُحفظ البيانات المحلية للاستخدام دون اتصال. لا تُمسح بيانات المحفظة عند تحديث الملفات.

## الخصوصية والقيود

تبقى المحفظة والتدفقات والسجل والنسخ الاحتياطية في `localStorage` على جهاز المستخدم. الأسعار الخارجية قد تتأخر أو تفشل؛ تظهر الحالة والمصدر ووقت السعر. التحليل تعليمي وليس توصية استثمارية.
