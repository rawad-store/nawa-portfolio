# نواة — دليل التشغيل والنشر

«نواة» تطبيق ويب تقدمي ثابت باللغة العربية لإدارة قائمة متابعة مستقلة عن محفظة الملكية الفعلية، مع تحليل فني، سجل تحليلات، سجلات تداول وتدفقات نقدية، ونسخ احتياطي محلي. لا يحتوي على خادم أو تداول آلي.

## النشر إلى GitHub Pages

1. فك ضغط الحزمة وارفع **محتوياتها كاملة** إلى جذر مستودع GitHub باسم `portfolio`، مع إبقاء `index.html` و`manifest.webmanifest` و`sw.js` و`assets/` و`data/` و`icons/` في الجذر.
2. فعّل GitHub Pages للمستودع من فرع النشر ومجلد الجذر (أو إعداد GitHub Actions المعتمد لديك)، ثم انتظر حتى يصبح الموقع متاحًا عبر HTTPS.
3. يكون عنوان المشروع المتوقع `https://rawad-store.github.io/portfolio/`. المسارات داخل التطبيق نسبية لتعمل في هذا المسار الفرعي.
4. لا تُضمّن ملفات مصدر إضافية فيها معلومات شخصية. الحزمة لا تحتوي على كميات الملكية الفعلية؛ زر «تحميل القائمة التجريبية» يستخدم بيانات اصطناعية معلّمة بوضوح. أما بيانات المستخدم الفعلية فتبقى في `localStorage` ولا تُرسل إلى GitHub.

## التثبيت والعمل دون اتصال

افتح الموقع مرة واحدة مع اتصال بالإنترنت كي يسجل Service Worker ويخزن غلاف التطبيق وأرشيف VLMRA المحلي. بعد ذلك يمكن تثبيت التطبيق من متصفح يدعم PWA واستخدام الواجهة دون اتصال. الأسعار والشموع الخارجية ليست بثًا حيًا عند انقطاع الشبكة: يعرض التطبيق آخر قيمة ناجحة محفوظة مع حالتها ومصدرها ووقتها، أو يوضح عدم توفر السعر. لا تُخزّن استجابات وسيط الأسعار المشتركة في Cache Storage؛ تُحفظ لقطة السعر محليًا في المتصفح.

عند تغيير ملفات التطبيق، رُفع إصدار اسم الكاش في `sw.js` لإتاحة النسخة الجديدة، وتحقق من إعادة فتح التطبيق بعد التحديث. مسح بيانات الأسعار من الإعدادات يزيل بيانات السوق المحفوظة محليًا ولا يمسح قائمة المتابعة أو سجل الملكية.

## البيانات والخصوصية

تبقى كميات الملكية ومتوسطات التكلفة والتدفقات والسجلات والنسخ الاحتياطية في `localStorage` على أصل الموقع في متصفح المستخدم. يتطلب نقلها إلى نطاق أو جهاز جديد تنزيل نسخة احتياطية من الإعدادات ثم استعادتها في النسخة الجديدة؛ تغيير النطاق يغيّر مساحة التخزين ولا ينقلها تلقائيًا. يُرسل رمز الأصل إلى وسيط الأسعار عند التحديث، وليس كمية الأسهم أو متوسط التكلفة. يحتفظ التطبيق بمفاتيح التخزين القديمة؛ تغيير قيم العرض التجريبي لا يمحو المحفظة الموجودة في المتصفح.

### تاريخ VLMRA

عند غياب شموع VLMRA.CA من Yahoo، يستخدم التطبيق أرشيفًا يوميًا محليًا جُمّع من صفحة علاقات المستثمرين الرسمية لشركة Valmore: <https://ir.valmore.com/en/share-and-corporate-information>. آخر التقاط للملف كان 2026-11-04 09:29 UTC، وآخر جلسة فيه 2026-11-03. يتضمن 1,198 شمعة صالحة من أصل 1,245 سجلًا؛ استُبعد 45 سجل OHLC غير متسق وأزيل تكراران. يضم الملف بيانات المصدر المطابقة للجنيه وmetadata قابلة للمراجعة. هذا الأرشيف لقطة تاريخية وليس تغذية أسعار حية؛ تظهر صفحة التحليل مصدر التاريخ وآخر شمعة. لا تُنشأ منه شموع ساعة أو أربع ساعات. إذا لم يتوفر حد البيانات المطلوب، تُعرض المؤشرات الممكنة بوصفها قراءة محدودة بلا توصية حاسمة أو خطة صفقة.

## القيود المالية

المؤشرات الفنية والدرجات آلية تعليمية وليست احتمالًا إحصائيًا للربح أو توصية استثمارية. تُحسب قيمة الملكية والتغير اليومي من الأسعار والكميات المتاحة وتظهر حالات النقص والتقادم. متوسط تكلفة الشراء تقديري، والربح/الخسارة المعروض غير محقق قبل البيع؛ لا يشمل الرسوم والضرائب والتوزيعات أو الأرباح المحققة ما لم يُذكر خلاف ذلك. التدفقات النقدية سجلات منفصلة ولا تُعامل كأرباح.

لا يُعامل متوسط التكلفة المجهول كأنه صفر: المراكز التي لا يُعرف متوسط تكلفتها تُستبعد من ربح/خسارة الملكية، ويُوسم الإجمالي بأنه جزئي. لا يسمح التطبيق بدمج شراء جديد مع كمية قائمة مجهولة التكلفة قبل إدخال متوسطها يدويًا، تفاديًا لعرض متوسط أو ربح مضلل. تُرفض شموع OHLC التي تخالف نطاق `low ≤ open, close ≤ high` وتُعرض أعداد السجلات المستبعدة. وتظهر الأسعار الموسومة من المصدر بأنها «متأخرة» بهذه الحالة في التقرير والجدول ولا تُسمّى أسعارًا لحظية.

## صيانة البيانات الاحتياطية

- حدّث `manifest.webmanifest` و`sw.js` مع كل تغيير في ملفات الواجهة أو أيقونات PWA.
- أضف كل مورد محلي أساسي إلى `SHELL_URLS` كي يعمل التطبيق عند فتحه دون اتصال.
- عند استبدال سجل VLMRA، حافظ على بنية ملف JSON وحقول المصدر وتاريخ الالتقاط وعدد السجلات المستبعدة؛ لا تدمج شموعًا من أطر زمنية مختلفة ولا تُعدّل أسعارًا تاريخية بصمت.
- حافظ على مفاتيح `localStorage` الحالية (`u_*` و`u_hold_*`) وعلى قبول النسخ الاحتياطية الأقدم عند استيرادها.
