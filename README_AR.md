# نواة | منصة الأسواق والمحفظة — الإصدار 2.2.0

منصة عربية لمتابعة الأسواق والتحليل الفني وإدارة سجل المحفظة، تعمل كتطبيق ويب تقدمي (PWA).

## ما الجديد في 2.2.0؟
- إعادة تصميم مرئية كاملة للهوية والألوان والتسلسل البصري.
- واجهة زمردية داكنة بلمسات ذهبية.
- شريط أقسام أكثر وضوحًا وتثبيت أثناء التمرير.
- تحسين بطاقات البيانات والحقول والجداول والأزرار.
- تحسين العرض على الهاتف والكمبيوتر.
- تحديث Service Worker لإصدار ذاكرة تخزين مؤقت جديد.

## النشر على GitHub Pages
1. فك ضغط الحزمة.
2. افتح مجلد `nawa_pro`.
3. ارفع محتوياته إلى جذر المستودع المنشور على GitHub Pages.
4. لا تحذف مجلدات `data` أو `assets` أو `tests` الموجودة لديك، ولا تستبدل أي ملفات بيانات خاصة بك.
5. بعد اكتمال النشر، افتح الموقع باستخدام `Ctrl + Shift + R`.

## ملاحظات مهمة
- بيانات المحفظة المحلية مرتبطة بنطاق الموقع والمتصفح؛ لا تمسح بيانات الموقع قبل تصدير نسخة احتياطية.
- لم تتغير معادلات التحليل أو حسابات المحفظة في هذا الإصدار.
- بيانات الأسعار قد تتأخر أو تتعذر حسب المصدر والاتصال؛ تحقق من وقت السعر ومصدره.
- راجع `QA_REPORT_AR.md` لمعرفة نطاق الاختبارات وحدودها.
